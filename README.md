# Диктовка — приватный архив выпусков

Здесь сохраняются готовые установщики **DMG**, **ZIP** и их контрольные суммы.

- [Все выпуски](https://github.com/yakovlevonline/dictation-updates/releases)
- [Последний готовый выпуск](https://github.com/yakovlevonline/dictation-updates/releases/latest)

## Установка из файла

Для Mac с Apple Silicon (M1 и новее), macOS 13 и новее.
Перед заменой закончите диктовку, дождитесь расшифровки и полностью завершите старое приложение.
Скачайте DMG и перенесите приложение в «Программы» либо распакуйте ZIP и откройте новую копию.
Установщик может найти предыдущую версию и сохранить резервную копию.

Это тестовые локальные сборки без Developer ID и нотарификации Apple: macOS может
показать предупреждение о неподтверждённом разработчике и повторно запросить разрешения.
Архив сохраняет файлы выпуска; их скачивание не заменяет локальную установку автоматически.

## Обновления и данные

**Обновления из приложения отключены.** Этот приватный репозиторий используется
как ручной архив установщиков, а не как канал автоматических обновлений.
История изменений доступна в настройках приложения и в описаниях выпусков.

Исходный проект разработки остаётся локально. В архив не выгружаются модели,
записи, личные настройки и ключи подписи. Модели, настройки и история хранятся
отдельно от приложения; после замены повторно скачивать готовую модель не нужно.
Распознавание работает на компьютере без сети после загрузки модели.
