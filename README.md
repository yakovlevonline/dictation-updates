# Диктовка для Mac

Голосовой ввод текста с распознаванием на вашем компьютере.
Для Mac с Apple Silicon (M1 и новее), macOS 13 и новее.

## Скачать и установить

Откройте [последний выпуск](https://github.com/yakovlevonline/dictation-updates/releases/latest)
и скачайте файл **Dictation-…-AppleSilicon.zip**.

1. Если старая «Диктовка» запущена, закончите диктовку и полностью завершите приложение.
   Распакуйте ZIP и откройте новую «Диктовка.app».
2. Приложение предложит установку или найдёт предыдущую версию и предложит обновление.
3. При первом запуске выберите языки, разрешите микрофон и вставку текста,
   скачайте выбранную модель и попробуйте короткую фразу.

Есть и обычный DMG с перетаскиванием приложения в «Программы».
Это тестовая сборка без Developer ID и нотарификации Apple: macOS может показать
предупреждение о неподтверждённом разработчике и повторно запросить разрешения
после обновления. Их состояние видно в настройках приложения.

## Как обновляться дальше

В «Диктовке» откройте **Настройки → Обновления → Проверить обновления**.
Приложение покажет описание новой версии и предложит установить её.
Также можно получить новый ZIP от автора и открыть приложение из него.
Перед заменой закончите диктовку и дождитесь расшифровки.

В версиях 3.0–3.0.2 встроенного обновления ещё нет: версию 3.1.0 нужно один раз
установить файлом. Модели, настройки и история сохраняются отдельно от приложения;
повторно скачивать готовую модель после обновления не нужно.

## Изменения и данные

История изменений доступна в настройках приложения и в описаниях выпусков здесь.
Для распознавания речи сеть не нужна после загрузки модели.

Этот репозиторий хранит готовые выпуски и подписанный канал обновлений.
Исходный проект разработки, модели, записи, личные настройки и секретный ключ
подписи в репозиторий не загружаются.
